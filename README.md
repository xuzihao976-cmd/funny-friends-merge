# 相亲相爱一家人 · 张张想不到！

用朋友照片制作的十级下落合成小游戏。首次打开默认 **原照版**，页面顶部可随时切换 **漫画版**；切换时会保留当前棋盘与分数。

## 玩法

移动鼠标后点击，或在手机上按住拖动并松手，投放头像。相同等级相碰就升级；堆到警戒线会结束。键盘也可用空格投放、左右方向键瞄准、`R` 重开。

合出第 5 级后，后续生成的新头像有 12% 的机会从已经合出的第 5 级及以上头像中出现。级别越高，出现越稀有。落地、合成、解锁、切换和结束等动作有音效，可在页面中关闭。

进化图鉴初始仅展示第 1 级；每个等级必须由玩家实际合出，才单独解锁该等级的头像和外号。进度保存在当前浏览器中，重新开局或切换画风不会清除。图鉴隐藏仅是前端玩法效果，静态网站上的图片文件本身可公开访问。

## 画风与音效

页面顶部可切换原照版和漫画版，也可关闭音效。头像使用网站内置素材；页面没有照片上传、导入或导出功能。

网站为纯静态页面，无需构建或后台服务。内容安全策略限制脚本、图片与音效的加载来源。此前版本保存在浏览器中的自定义照片数据不再读取。

音效来自 Kenney 的 CC0 [Interface Sounds](https://kenney.nl/assets/interface-sounds) 与 [Impact Sounds](https://kenney.nl/assets/impact-sounds)。所用文件见 `assets/sfx/SOURCE.md`。
